# 25-akita-bear-sighting: 秋田県ツキノワグマ・野生鳥獣出没タイムライン

## 依頼内容

> 秋田県内で報告されたツキノワグマ・イノシシ・シカの出没情報（クマダス、約2.5万件）を、2022年から2026年までの時系列スライダーで月・季節ごとに再生し、出没種別（クマ、痕跡、シカ、イノシシ）の切り替えや、カーソルを合わせた地点の詳細（日時・場所・状況）を確認したい。外部ライブラリなしでPCブラウザで軽快に動かしたい。

## 目的と背景

近年、東北地方を中心にツキノワグマの人里や市街地への出没・人身被害が深刻化しています。秋田県では「ツキノワグマ等出没情報（クマダス）」として、県民や警察等からの目撃・痕跡・被害情報をオープンデータとして公開しています（Hugging Face: `yuiseki/akita-kumadas-wildlife-sighting`）。

この約2万5000件の時系列空間データを、重い汎用地図ライブラリ（MapLibre 等）を一切使わず、WebGL2 の最小シェーダーとベイク済みバイナリで描画します。
全レコードを最初に GPU の頂点バッファへ送り、フレームごとは uniform 1つの更新で済ませることで、スライダーの高速スクラブや 120Hz/60Hz の滑らかな時間再生、種別フィルタリング、マウスホバーによる即時ピックを実現します。
