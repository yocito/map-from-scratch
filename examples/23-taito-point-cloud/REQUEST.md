# 台東区の点群 PNG を 3D で見る

産総研・地質調査総合センターが公開する[統合点群 PNG タイル](https://tiles.gsj.jp/tiles/pcpng/mixed/index.html#taito)から、台東区周辺を表示する例です。元データは東京都デジタルツイン実現プロジェクトの区部点群です。

配信形式は PNG という名前ですが、実際のタイル画像は**可逆 WebP**です。[点群 PNG 1.0 仕様のアーカイブ](https://web.archive.org/web/20251107133417/https://gbank.gsj.jp/seamless/pcpng/1.0/)に従い、画像の RGB 画素を X・Y・標高・色の列として復号します。Web メルカトル座標は浅草付近を原点とするメートル単位に変換してから、WebGL2 の点として描きます。GSJ のタイルでは標高の係数が 2 で、1 cm 単位です。

視点距離から z14〜20 の解像度を選び、中心周辺の 5×5 タイルだけを取得します。取得は最大5件を並列に行い、読み込み済みの点群はメモリに保持します。GPU 側の点群が約120 MiB を超えた場合、古いタイルを破棄します。地図エンジンや点群描画ライブラリは使いません。

雷門・浅草寺・上野・御徒町へ移動できます。ドラッグで回転、右ドラッグまたは Shift＋ドラッグで移動、ホイールで拡大縮小できます。点の大きさも調整できます。

性能計測は未実施です。点の位置と色の復号については小さなデータを使った自動テストを追加しました。広い範囲での見え方は目視確認が必要です。
