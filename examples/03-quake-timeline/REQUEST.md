# 03 2025 年の地震を再生する

## 依頼

> 2025年に世界で起きた M4.5 以上の地震を、地図の上で時間を追って再生したい。再生・一時停止と、スライダーで好きな日時に飛べるように。PC のブラウザで見る。

## 読み取った要件

| 要件 | 数値にしたもの |
| --- | --- |
| 再生が滑らか (PC、高リフレッシュレートも) | 1 年を 600 フレームで再生しながら 8 倍までズームインとズームアウトをして、frame_ms p95 8.3 ms 以下 (120 Hz) |
| スライダーでどこへでも飛べる | フレームごとの JS 時間 cpu_ms p95 0.5 ms 以下。時刻を変えてもデータの再転送が起きない |
| いつどこで起きたか分かる | ミャンマー M7.7 (2025-03-28) の震央が、1 日前は陸の色、30 分後は赤であることを毎回確かめる |
| すぐ見られる | 初回描画 p50 500 ms 以下、データ gzip 600 KB 以下 |

## やらないこと

3D、地球儀、国境、地名、タイル、震源の深さの立体表示、イベントのクリック。説明文は「画面上でいちばん大きい地震」1 行だけを DOM で出す。

## 設計

- 8,502 件を読み込み時に全部 GPU へ送る (1 件 12 バイト: 位置 u16×2、年初からの分 f32、マグニチュードと深さ u8×2)。
- フレームごとに変えるのは `u_time` だけ。頂点シェーダが経過時間から「まだ起きていない / 波紋が広がる / 薄れながら残る / 消えた」を決め、見えない点は gl_PointSize 0 で捨てる。CPU 側で可視判定やソートをしないので、どの時刻へ飛んでもコストは同じ。
- 1 フレームの描画は、陸の塗り 1 回と点 1 回の 2 ドローコール。
- 大きさはマグニチュードの指数 (1 増えると 1.8 倍)、色は深さ (70 km 未満は赤、300 km 未満は黄、それより深いと青)、発生から 12 時間は波紋が広がる。
- 投影は 02 と同じく Equal Earth をベイク時に済ませる。
